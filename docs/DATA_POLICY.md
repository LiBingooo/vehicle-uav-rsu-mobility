# Data Use

Real vehicle trajectories are obtained from [highD](https://levelxdata.com/highd-dataset/) under the provider's terms. Request access directly from the provider and follow its conditions for use, citation and sharing. The dataset and modified versions must not be redistributed.

This repository includes synthetic example outputs. It does not include highD trajectory files or highway background photographs.

Exports created from local highD recordings may contain dataset information and remain subject to the same terms. Converting data to a visualization does not remove those conditions.
